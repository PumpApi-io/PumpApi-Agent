## What is PumpApi Agent?

**PumpApi Agent** is the agent interface behind [pumpapi.ai](https://pumpapi.ai), a hosted AI agent you can rent, fund and command from your browser or messenger.

It is designed for people who want useful automation without setting up servers, terminals or local developer tools. You tell the agent what you want in plain English, and it can help you build things like:

- Solana trading bots
- pump.fun snipers and monitors
- copytrading bots
- market dashboards
- backtests for trading strategies
- websites and landing pages
- scripts, apps and general automations
- 24/7 chain watchers and alerting tools

The agent lives online, so it can keep working after you close your laptop.

## Built for Solana trading automation

PumpApi Agent is especially useful for Solana traders and builders because it comes with preinstalled PumpApi skills for the [pumpapi.io](https://pumpapi.io) API.

### Preinstalled PumpApi skills

The agent includes ready-to-use knowledge and workflows for:

| Area | What the agent can help with |
|---|---|
| **pump.fun API** | New token monitors, sniper bots, buy/sell automation, token launch tracking |
| **Solana** | Wallet-aware automations, token transfers, transaction monitoring, on-chain data workflows |
| **Raydium** | Trading and monitoring flows around Raydium Launchpad and Raydium CPMM |
| **Meteora** | Support for Meteora Launchpad, DAMM and related trading automation |
| **PumpApi.io data stream** | Real-time event monitoring through WebSocket streams |
| **Backtesting** | Strategy testing on historical market data before going live |

Under the hood, the agent knows how to use [pumpapi.io](https://pumpapi.io), the fast API for pump.fun, Raydium, Meteora and Solana token operations.

That means you can ask for things like:

```text
Build me a pump.fun bot that watches new token launches,
filters for large dev buys, backtests the strategy,
and only then runs it live with Telegram alerts.
```

Or:

```text
Create a dashboard that tracks wallets buying new pump.fun tokens
and shows which tokens got the most early volume.
```

## How it works

Launching an agent on [pumpapi.ai](https://pumpapi.ai) takes five simple steps.

| Step | What happens |
|---|---|
| **1. Pick your server** | Choose the machine your agent will run on. Start small and upgrade later if needed. |
| **2. Pay with crypto** | Top up your server balance using supported crypto payments. |
| **3. Wait for deployment** | The system installs and configures your agent automatically. This can take up to 30 minutes. |
| **4. Top up your LLM balance** | Add funds for AI model usage, so your agent can think, code and chat. |
| **5. Start chatting** | Open the agent and tell it what to build, test or run. |

## Example use cases

### 1. Build a pump.fun sniper bot

Ask the agent to watch new token launches, filter for your conditions, simulate the strategy on historical data and then run it live if the results look good.

```text
Backtest a pump.fun sniper strategy for the last 2 hours.
Buy only if the dev buy is above a threshold, then simulate TP and SL rules.
Show me the win rate and worst drawdown before we go live.
```

### 2. Monitor wallets

Track wallets that often enter early, then receive alerts when they buy or sell.

```text
Watch these Solana wallets and alert me when they buy a new pump.fun token.
Include token address, buy size and market cap if available.
```

### 3. Create a copytrader

Turn a list of wallets into a small copytrading bot with risk limits.

```text
Make a copytrader that follows these wallets,
buys at most 0.02 SOL per token,
and sells when the original wallet exits.
```

### 4. Build a dashboard

Ask for a browser dashboard that shows recent tokens, wallet activity, volume or strategy performance.

```text
Build me a web dashboard for new pump.fun launches.
Show token age, volume, number of buys, dev activity and links to charts.
```

### 5. Automate non-trading work

PumpApi Agent is not limited to trading. It can also help with websites, apps, data analysis, research, content, scripts and other automations.

## Project architecture

This repository contains the web UI and backend pieces used by PumpApi Agent.

| Part | Purpose |
|---|---|
| `frontend/` | Browser interface for chatting with the agent |
| `backend/` | Backend server that connects the UI to the agent runtime |
| `install/` | Installation scripts and dependency files |
| `scripts/` | Update scripts and PumpApi Agent configuration files |

PumpApi Agent is based on Hermes Agent and is configured to work with PumpApi's hosted model gateway, the web UI and messenger integrations.
